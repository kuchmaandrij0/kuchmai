# KUCHMAI SHOP

Автомобильный лендинг с белым Volkswagen Transporter T5 и реалистичным чехлом. Чехол остаётся на месте: мягкий луч под курсором проявляет автомобиль сквозь ткань. На телефоне свет перемещается касанием и движением пальца; прокрутка страницы сохраняется. С клавиатуры Enter/пробел включают свет, стрелки перемещают его, Escape выключает. Эффект учитывает prefers-reduced-motion.

## Запуск

Требуется Node.js 18 или новее. Внешних npm-зависимостей нет.

```sh
cd /workspace/kuchmai
npm start
```

Сервер слушает порт 3000; можно задать `PORT`. Статические файлы и шрифты находятся в `public/`.

## Статус

Главная страница, карточка автомобиля, категории запчастей и форма запроса реализованы. Заявки сохраняются только в localStorage браузера. Перед настоящим запуском магазина необходимо подключить обработку заявок, реальные контакты и каталог. Публичный хостинг не подключён.
