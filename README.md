# KUCHMAI SHOP

Автомобильный лендинг с белым Volkswagen Transporter T5 и реалистичным чехлом. Чехол остаётся на месте: мягкий луч под курсором проявляет автомобиль сквозь ткань. На телефоне свет перемещается касанием и движением пальца; прокрутка страницы сохраняется. С клавиатуры Enter/пробел включают свет, стрелки перемещают его, Escape выключает. Эффект учитывает prefers-reduced-motion.

## Запуск

Требуется Node.js 18 или новее. Внешних npm-зависимостей нет.

```sh
cd /workspace/kuchmai
npm start
```

Сервер слушает порт 3000; можно задать `PORT`. Статические файлы и шрифты находятся в `public/`.

## Статус

Главная страница, карточка автомобиля, категории запчастей и форма запроса реализованы. Заявки сохраняются только в localStorage браузера. Перед настоящим запуском магазина необходимо подключить обработку заявок, реальные контакты и каталог. Публичный хостинг не подключён.

## Honda M-NV: сборка на ходу

Раздел KUCHMAI LAB (`#assembly`) запускается кликом по свободному месту сцены или кнопкой с клавиатуры. Колёса уже катятся, затем их догоняют платформа, батарея и электромотор; панели кузова и бамперы прилетают с разных сторон. После сборки дорога и колёса продолжают движение. Есть повторный запуск.

Внешний вид белой Honda M-NV воссоздан по предоставленному фотореференсу; изображение автомобиля сгенерировано. Части одного изображения компонуются в Canvas 2D. Это художественная анимация, а не инженерная модель сборки. WebGL и внешние зависимости не нужны. При уходе со сцены движение приостанавливается; настройка сокращения движения показывает неподвижный готовый автомобиль.

Сцена использует отдельные сгенерированные изображения дороги и открытого шасси. Диски вращаются в нормализованной плоскости и проецируются обратно в фиксированные эллипсы; центры ступиц, внешний контур шин и кузов сохраняют положение. Для обоих колёс используется одна угловая скорость. Движение зерна асфальта добавляется поверх фотореалистичного дорожного фона.
